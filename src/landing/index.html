Stop staring at raw code. RepoLens analyses any public repository — scripts, dependencies, README, structure — and generates a beautiful static site you can understand in 2 minutes.

Get started instantly
npx repo-lens generate storybookjs/storybook

Replace storybookjs/storybook with any public GitHub repo. Output lands in ./dist.

Under the hood

How it works

  1. 1
    Fetch

    Pulls the repo tree, README, and package.json via the GitHub API. No cloning required.

  2. 2
    Analyse

    Heuristics detect project type, entry points, key scripts, dependencies, and the install instructions — no AI, no guessing.

  3. 3
    Generate

    A clean static index.html + CSS is written to ./dist. Deploy anywhere — GitHub Pages, Netlify, or just open it locally.

What's included

Features

⚡

Instant output

One command. No config files, no setup, no API keys for public repos.

🔍

Smart heuristics

Detects Next.js, React, Vue, Go, Python and more from files and deps — not guesswork.

📄

README-first

Hero images, install instructions, and intros are pulled directly from the README.

🌙

Dark mode

Generated sites respect the visitor's system preference automatically.

🚀

GitHub Pages ready

A workflow is included to auto-deploy on every push via GitHub Actions.

🎨

Custom templates

Pass --template ./my-template to use your own HTML/CSS layout.
